# Changelogs

Each component has its own version, release tag and history:

| Component | Changelog | Version source | Release tags |
| --- | --- | --- | --- |
| Windows AIMP plugin | [Windows](docs/changelogs/windows.md) | [windows.properties](versions/windows.properties) | `windows/vX.Y.Z` (historical `vX.Y.Z` tags retained) |
| Android companion | [Android](docs/changelogs/android.md) | [android.properties](versions/android.properties) | `android/vX.Y.Z` |
| Shared shuffle core | [Core](docs/changelogs/core.md) | [core.properties](versions/core.properties) | `core/vX.Y.Z` |

See [versioning](docs/versioning.md) for bump rules and [releasing](docs/releasing.md)
for publishing. An app release records the bundled core version; matching version
numbers across components are not required.
