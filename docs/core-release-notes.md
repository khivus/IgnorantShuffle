# IgnorantShuffle Core v0.1.0

First explicit version of the portable C++ shuffle rules already shared by
Windows and Android. This versioning update changes no selection algorithms.

GitHub's source archives capture the entire repository. The core has no separately
installed runtime; releases include both apps, each with its own version, built
with this bundled core.

See [core history](changelogs/core.md), [versioning](versioning.md), and
[core-only builds](building.md#core-only-build).
