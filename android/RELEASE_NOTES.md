# IgnorantShuffle Android v0.12.1

## Playback defaults

- Default track cooldown is now 3 track starts.
- Switch before track end defaults to 150 ms.
- Reactive correction delay defaults to 0 ms. Combined switching remains optional.
- Existing saved values are preserved.

Android version: **0.12.1**, versionCode **15**. Bundled core: **0.2.0**.
Requires Android 8.0+; retains the application ID and pinned update signing key.
The Android companion remains a preview build.
