# IgnorantShuffle Windows v0.17.1

## Improvements

- Default track cooldown is now 3 track starts. Existing saved cooldowns are preserved.

## Fixes

- Opening Settings preserves local rules instead of importing an older shared file. Minimum eligible weight and Play playlist once stay as set. Shared settings still load at startup, when sharing is enabled, or through Reload shared; Publish current settings shares local edits.
- Refresh saved values when revisiting settings pages, including music folders and update preferences.
- Display custom learning strengths and limits accurately and preserve them when applying unchanged settings.

Windows version: **0.17.1**. Bundled core: **0.2.0**. Includes x64 and x86.
